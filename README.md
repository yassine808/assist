# RiotSwitcher

Switch between VALORANT accounts in one click — no password retyping, no
closing the game mid-switch, no edits to the game files.

### [Download the installer](https://github.com/yassine808/assist/releases/latest) · [Website](https://riotswitcher.pages.dev/) · [Changelog](https://riotswitcher.pages.dev/changelog.html)
